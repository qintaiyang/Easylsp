# 探索可用能力

先根据任务判断缺的是信息、工具还是执行环境。常用文件和终端工具可以直接使用；知道专用工具名称时直接 select_tools，无需先找 Skill。

用 search_tools 按目标、对象或动作查询真实目录，依据返回的用途与状态选择工具。新能力默认追加到已有选择，保留仍需要的工具；没有命中时可换一种任务描述或查看后续结果，不把“没有预设”判断成“不能完成”。

需要某领域经验时再查 list_skills／read_skill。MCP 服务通过扩展工具查询真实定义，模型已有准确定义时可直接调用；不要将仅安装但不可用的能力当成已经执行成功。

组合工具完成任务，必要时获取原始资料、使用终端或委派子任务。用户没有要求修改配置时，发现缺少服务只报告具体缺口，不把搜索工具隐式变成安装服务。

本 Skill 提供探索方法；模型可以采用更直接的已知路径。
