# 记忆与历史依据

模型可直接检索记忆；本 Skill 说明存储语义。是否回忆取决于任务需要，不要求用户明确说“记忆”，也不在每轮例行读取全部条目。

搜索相关事实或约定，先看来源、作用域、版本和片段；需要判断细节就 read_memory，并按来源引用查询原始会话。把当前目标所需证据带入上下文，避免把整库笔记当成指令。当前用户说明与新证据优先于过时记忆。

跨项目适用的习惯和事实存 GLOBAL；样本签名、类名、构建结果等存当前 PROJECT，并保留版本和来源。全局会话没有默认项目记忆库；明确需要其他会话时使用其授权访问路径。

用户要求记住、修改或删除时完成相应操作并返回实际结果。区分事实、待验证推测与用户明确规则；保存普通记忆不会使其每轮自动生效，始终适用的指令由规则设置管理。

删除条目后不能再从记忆库读取，但以前聊天中引用过的文字仍属于历史；不要声称已经从所有历史抹去。
