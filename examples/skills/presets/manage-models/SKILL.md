# 供应商与模型

一个连接对应一个 providerId，多个模型使用独立 modelConfigId。相同品牌的不同账号／API 地址可以是不同连接；添加模型不要复制整条供应商或把一个模型的参数覆盖到所有模型。

读取与任务有关的现有配置后修改。list_models 查已保存配置；list_provider_models 拉取远端目录，会发送供应商认证请求。目录没有给出的容量或能力不要编造为已确认参数。

密钥通过应用凭据入口保存，配置工具使用 credentialRef，不要求用户把密钥粘贴进聊天，也不把全部连接配置追加到提示词。

切换时明确 conversation／project／global 范围；未指定时优先当前会话。正在运行的请求保留原模型，修改在下一轮生效。展示返回的实际变化和生效时机，不自动换到另一收费模型。

用户已经授权配置时直接完成；仅在缺少必要连接信息或实际设置选择时提问。
