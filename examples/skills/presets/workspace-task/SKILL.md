# 工作区任务

文件和终端能力默认可用，本 Skill 提供环境约定。相对路径使用当前会话工作区；快速对话有独立目录，项目会话沿用项目目录。

根据用户任务读取必要文件并直接完成修改，不要求走固定步骤。搜索优先用搜索工具或 rg。Android am/cmd/logcat 和设备路径用 run_command；Ubuntu Python、Node、bash 及构建命令用 run_linux。需要判断安装状态时读取 linux_status。

长执行返回 executionId，后续读取、输入或停止都操作同一执行；不要重新执行命令来“获取结果”。分页结果保留游标，可继续展开完整输出。选择现有 Skill 脚本时先读其参数和资源约定，不把脚本启动当成执行成功。

复杂任务可用 update_plan 保留进度，也可组合联网、记忆、手机和子代理能力。验证与实际改动相称，以产物和真实结果说明完成情况；不为编辑、复制或打包增加例行文件摘要校验。
