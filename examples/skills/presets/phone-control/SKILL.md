# 手机操作

phone_use 可直接使用，不要求先使用本 Skill。按用户的目标操作；结合实际状态选择节点、图片或手势，不增加固定的逐次点击确认。

- 需要界面依据时 observe：文本和控件可用 nodes；判断布局、自绘内容或图像时用 screen／both。图片必须实际传入当前模型，路径文本不是画面。
- 使用本次观察返回的 snapshotId、nodeId 和坐标尺寸。状态失效时重读当前页面；不要重复执行结果未知的点击。
- 应用名称或包名不明确时用 list_apps 查询实际入口，再通过 launch／open_uri 打开。set_text 支持中文并替换节点文本，输入完成不等于已经发送；是否发送由用户目标决定。
- 点击、手势返回 completed 只表示输入阶段完成。任务结果需要当前界面或其他实际证据支持。
- 多步骤过程中按需要观察和等待。需要设备条件时读取 status，返回的服务状态和支持集合优先于猜测。
- 手机被其他会话占用时先协调任务。交给子代理之前或本段手机任务完成后调用 release；这只归还设备，后续仍能使用工具。

说明实际完成的结果及尚未确认的部分。需要文件或其他工具时可以直接组合使用，不受本包建议工具组限制。
