# 会话、分支与子代理

会话读取无需启动模型；查询实际需要的历史和原始输出，返回的 ID 与消息引用可继续使用。create_conversation 只创建会话，send_to_conversation 才提交任务。

fork_conversation 创建能独立继续的新会话，源会话保持不变。边界使用已完成轮次，不复制尚未完成的工具调用；当前轮新增的事实放进任务说明或资源引用。

复杂任务可拆成独立子任务；共享文件和同一手机屏幕的冲突由任务划分解决。spawn_agent 可指定模型、任务、上下文方式及资源；提供充分的目标、约束与证据，避免只给一句含糊指令或复制无关全集。

子代理继承权限上限，可以读写、执行、选择工具与继续委派。调度依据实际资源和用户设置，等待会让出执行槽；没有固定只读、三个代理或一层派生的工作流限制。

任务接受回执不是完成结果。通过状态和结果引用跟进，必要时读取完整子会话，整合可验证结论。父子手机任务交接前归还设备占用。停止执行树不影响已经独立创建的分支。
